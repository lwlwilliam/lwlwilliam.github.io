# blog-editor — hugo 博客写作小工具

一个纯 Go 的小型本地编辑器，界面内嵌在二进制里（无外部依赖、无需登录），专为这个 hugo 博客定制：

- **Markdown 实时预览**：正文与预览左右分栏，边写边看；预览由 goldmark（和 hugo 同款内核）渲染，代码块用 monokai 高亮，数学公式走本站自带的 KaTeX。
- **上传图片**：自动写入 `static/assets/images/<年>/<月日>/`（如 `static/assets/images/2026/1106/foo.png`），并把**相对路径**（如 `../../../static/assets/images/2026/1106/foo.png`）以 `![]()` 形式插到光标处，与现有文章写法一致。
- **上传文件**：写入 `static/assets/files/`，插入 `[文件名](相对路径)`。
- 直接**拖拽 / 粘贴截图**到编辑器也能上传并插引用，无需点按钮。
- **文章目录**：按年份折叠展开（2026 → 2025 → …），另有"单页"分组；点击任意文件即可重新编辑、实时预览。
- **新建文章**：按 `new_post.py` 的约定生成 `content/posts/<年>/<日期>-<slug>.md` 与 front matter（`date/title/categories/keywords`）。
- **一键构建**：界面内直接运行 `hugo --cleanDestinationDir`（构建时自动清掉 `docs/` 里源码已不存在的陈旧文件），失败时弹窗显示 hugo 输出。
- **行内删除**：右键文章里的图片/文件链接（指向 `static/assets`）→「删除文件并移除引用」会真删文件并清理该处 markdown；有确认弹窗，会提示其他文章引用、模板引用与“文件不存在”等情况；删空的年月目录自动回收。

## 运行

```bash
cd blog-editor
go run .            # 需要本机装有 Go
```

编译成常驻二进制更省心：

```bash
cd blog-editor
go build -o ~/bin/blog-editor .
~/bin/blog-editor          # 在仓库任意位置运行都会向上查找 hugo 根目录
```

启动后自动打开 `http://127.0.0.1:<port>`（仅监听本机回环地址）。

参数：

| 参数 | 默认 | 说明 |
|---|---|---|
| `-port` | `8377` | 端口，被占用时自动顺延 |
| `-open` | `true` | 启动时是否自动开浏览器 |
| `-root` | 自动 | Hugo 根目录（默认从当前目录向上找 hugo 配置文件） |

## 快捷键

- `⌘S / Ctrl+S` 保存
- `⌘B / ⌘I` 加粗 / 斜体
- 粘贴（⌘V）截图 → 自动上传图片并插入引用

## 一些约定

- 保存只写 `content/` 下的 `.md` 文件；`static/` 与上传接口只接受指定目录，路径白名单防逃逸。
- 插入的图片引用是**相对于文章文件的路径**（`content/posts/<年>/x.md` 为三级 `../../../`），与本仓库既有文章保持一致。
- 上传文件重名会自动加 `-1`、`-2` 后缀；文件名会做安全清洗（空格转 `-`，保留中文）。
